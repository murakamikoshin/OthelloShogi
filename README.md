# （ゲーム名は検討中）

将棋の駒を「打つ」と、挟んだ相手の駒が裏返って自分の駒になり成る。
成った駒の新しい利きでさらに挟みが成立すれば、連鎖する。

現在の進捗: **Phase 0（ルールエンジン）完了 / 連鎖反転 対応済み**

> 名称について: 「オセロ」はメガハウスの登録商標のためタイトルに使わない。
> 同名の変則将棋（八王子将棋クラブ考案「オセロ将棋」）も存在するため、別名を検討中。

## 動かしてみる

初回だけ:

```bash
npm install
```

### テストを実行する

```bash
npm test
```

ルールが仕様どおりかを 80 個のテストで確認します。全部 ✓ になれば OK です。

### 棋譜を流し込んで盤を見る

```bash
npm run cli -- kifu/sample.kifu           # 最終局面だけ表示
npm run cli -- kifu/chain.kifu --steps    # 2連鎖が起きる棋譜を1手ずつ表示
npm run cli                               # 初期局面だけ表示
npm run cli -- --moves                    # 初期局面の合法手を一覧表示
```

盤はこう表示されます（`^` が先手、`v` が後手、`・` が空マス）:

```
     c0  c1  c2  c3  c4  c5
r0   ・  ・  ・ v玉  ・  ・
r1   ・  ・  ・ v歩  ・  ・
r2   ・  ・  ・  ・  ・  ・
r3   ・  ・  ・  ・  ・  ・
r4   ・  ・ ^歩  ・  ・  ・
r5   ・  ・ ^玉  ・  ・  ・
```

### バランスを測る

```bash
npm run balance            # ランダム対局 400 局で反転・連鎖の起きやすさを測る
npm run balance -- 2000
```

`src/core/rules.ts` の数値（盤の広さ・持ち駒・連鎖上限・反転距離）を書き換えて
実行し直すと、設定を変えた効果を数字で比べられます。

## 棋譜の書き方

座標は必ず **row → col** の順。row 0 が後手側、row 5 が先手側。どちらも 0〜5。

| 書き方 | 意味 |
|---|---|
| `P*13` | 歩を row1 col3 に打つ |
| `R*33` | 飛を row3 col3 に打つ |
| `B*44` | 角を row4 col4 に打つ |
| `42-32` | row4 col2 の駒を row3 col2 に動かす |
| `pass` | パス（合法手が1つも無いときだけ） |

`#` 以降は行コメントです。`kifu/sample.kifu` に例があります。

## 実装済みのルール（Phase 0）

- 6×6 の盤、駒は 玉 / 歩 / 飛 / 角 の4種。成駒は と / 竜 / 馬
- 初期配置: 先手 玉(5,2) 歩(4,2) / 後手 玉(0,3) 歩(1,3)、持ち駒は両者 歩3・飛1・角1
- 毎ターン「打つ」か「動かす」のどちらか1つ
- **反転は「打つ」ときだけ**。打った駒の利きの方向 ＋ 縦横4方向に挟み判定を行い、
  挟んだ相手の駒を裏返す（`FLIP_DIRECTION_MODE = 'wide'`）
  - 歩を打っても横で挟めば裏返る。角は斜め（距離無制限）＋縦横1マス
  - `'attack'` にすると利きの方向だけ（歩は前1方向のみ）、`'all8'` にすると駒種によらず全8方向
- 裏返った駒は持ち主が変わり、**同時に成る**。すでに成駒なら成ったまま持ち主だけ変わる
- **連鎖反転**: 成った駒は新しい利きを持つので、その駒を起点にさらに挟みが成立すれば裏返る。
  これを反転が止まるまで（最大 `MAX_CHAIN` 段まで）繰り返す
  - 同一の駒は1手番中に2回以上反転しない
  - 各段の反転は「同時解決」。処理順で結果が変わらないことをテストで保証している
  - 1手ごとの連鎖数と、1局を通しての最大連鎖数を局面に記録する
- **玉は絶対に反転しない**。連鎖の起点にもならない。相手の玉に当たったらその方向は打ち切り。
  自分の玉は挟みの終端（アンカー）になる
- 移動による成りは無い。持ち駒を打つときは常に不成
- 移動で取った駒は持ち駒になる（成駒は不成に戻る）。玉を取ったら勝ち
- 二歩は無し。歩は最終段に打てない・動けない
- 王手放置は合法（詰み判定はしない）
- 合法手が無ければパス。両者が連続でパスしたら盤上の駒数が多い方の勝ち（同数は引き分け）
- 同一局面が4回出現したら盤上の駒数で決着

### バランス調整で変える前提の数値（`src/core/rules.ts`）

| 定数 | 既定値 | 意味 |
|---|---|---|
| `BOARD_SIZE` | 6 | 盤の一辺。ここを変えれば初期配置も棋譜表記も追従する |
| `INITIAL_HAND` | 歩3 飛1 角1 | 初期持ち駒。盤の埋まり具合＝反転の起きやすさに一番効く |
| `FLIP_DIRECTION_MODE` | `'wide'` | 挟み判定に使う方向。`'attack'`（利きのみ）/ `'wide'`（利き＋縦横）/ `'all8'`（全8方向） |
| `MAX_CHAIN` | 5 | 1手番の連鎖の段数上限 |
| `SLIDE_FLIP_RANGE` | 無制限 | 飛・角・竜・馬の走る方向の挟み判定の距離 |
| `STEP_FLIP_RANGE` | 無制限 | 歩・と金など1マスだけ利く方向の挟み判定の距離 |
